## Minimal WNSP Divergence Test (practical version)

### Goal

Prove in one run:

> ψ is constant
>
> channel state changes
>
> output changes deterministically

* * *

## 1\. Fixed input (no variation)

Make sure this is **hardcoded or hashed**, not regenerated:

```

ψ_input = load("birdsong_signature_v1")
ψ_hash  = hash(ψ_input)
```

* * *

## 2\. Capture baseline state

```

state_A = capture_channel_state()
```

Log it immediately (important for trust):

```

log("STATE_A", state_A.summary())
```

* * *

## 3\. Apply ONE controlled perturbation

Keep this simple and explicit:

```

activate_node("λ_aux_3")
```

or

```

shift_phase("λ_band_2", +0.2)
```

Then:

```

state_B = capture_channel_state()
log("STATE_B", state_B.summary())
```

* * *

## 4\. Run identical execution

No branching, no flags:

```

result_A = run(ψ_input, state_A)
result_B = run(ψ_input, state_B)
```

* * *

## 5\. Deterministic comparison

This part matters more than people think—make it readable.

```

print("INPUT_HASH:", ψ_hash)

print("RESULT_A:")
print(result_A.route)
print(result_A.entropy)
print(result_A.rank)

print("RESULT_B:")
print(result_B.route)
print(result_B.entropy)
print(result_B.rank)
```

* * *

## 6\. Explicit diff (don’t leave it implicit)

```

diff = {
  route_changed: result_A.route != result_B.route,
  entropy_delta: result_B.entropy - result_A.entropy,
  rank_changed:  result_A.rank != result_B.rank
}

print("DIFF:", diff)
```

* * *

## What you’re aiming to see

Not just “different”—but **traceable difference**:

- Route path changes

- Entropy shifts in a consistent direction

- Ranking reorders


And crucially:

> Same input hash printed for both runs

* * *

## One thing to avoid (this will kill credibility)

Do NOT let:

- randomness

- time-based seeds

- background async noise


affect the result.

If someone reruns it and gets different outputs again → the proof collapses.

* * *

## If you have time for one upgrade (optional but powerful)

Add:

```

assert ψ_hash_A == ψ_hash_B
assert state_A != state_B
assert result_A != result_B
```

That turns it from a demo into a **testable invariant**.

* * *

## Where this fits in your ecosystem

- Lives as a **single script** in your repo

- Runs in seconds

- Becomes your **reference proof**


You don’t need to market it.

Just make it runnable.

* * *

## Final note

You don’t need to prove everything.

You just need to prove one thing clearly:

> **Output is a function of channel state, not just input**

Do that once, cleanly—and everything else you’re building stands on firmer ground.
