---

## Short-term (current sprint)
- Ship a working, live product at wnsp.tech with real wallets, staking, LP pools, airdrop, Nostr/Telegram presence
- Grow the user base — get real people holding NXT and using the platform
- Hardware campaign funding via NXT tier purchases

## Medium-term (the vehicle)
- NexusOS + NXT token = crowdfunding and coordination layer for photonic hardware R&D
- The advocacy airdrop (85M NXT on Nostr) is the community-building instrument for this phase
- Target: Nostr/Bitcoin community — they already value decentralised, censorship-resistant systems and will grasp why physics-based addressing beats cryptographic hashing
- Goal: enough community + capital + credibility to manufacture SNIC / PHR-1 / Spectral Relay Mesh hardware
- The blockchain is NOT the end goal — it is the vehicle

## Long-term (~2032)
- Photonic computing ASICs arrive; NexusOS runs natively — no rewrite needed, it was already written in the language of photonic hardware (wavelengths, Ψ channels, Hilbert space)
- 25,600 orthogonal Ψ channels (256 WDM × 50 OAM × 2 pol) map directly to physical waveguide lanes — ⟨Ψᵢ|Ψⱼ⟩ = 0 by quantum mechanics, not software policy
- Kardashev Type I civilisation OS: physics-based communication and compute at civilisation scale

**Why this matters for build decisions:**
Every feature should either (a) grow the user/advocate base, (b) fund hardware R&D, or (c) prove the physics stack works at scale. If a feature does none of these, it is low priority.
